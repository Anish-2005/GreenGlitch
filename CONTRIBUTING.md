# Contributing to GreenGlitch

First off, thank you for considering contributing to GreenGlitch! It's people like you who make GreenGlitch a great tool for communities.

## Code of Conduct

By participating in this project, you agree to abide by the terms of our Code of Conduct. We expect all contributors to maintain a respectful and inclusive environment.

## How Can I Contribute?

### Reporting Bugs

- **Check for existing issues:** Before opening a new issue, please search the issue tracker to see if the bug has already been reported.
- **Use a clear title:** Summarize the problem concisely.
- **Describe the steps to reproduce:** Provide as much detail as possible so we can replicate the issue.
- **Provide environment details:** Include your browser, OS, and any relevant configuration.

### Suggesting Enhancements

- **Explain the "why":** Describe the problem you're trying to solve and why this enhancement would be useful.
- **Be specific:** Provide details about how the feature should work.
- **Mockups are welcome:** If it's a UI change, a simple sketch or screenshot is very helpful.

### Pull Requests

1. **Fork the repository** and create your branch from `main`.
2. **Install dependencies** using `npm install`.
3. **Make your changes.** If you've added code that should be tested, add tests!
4. **Ensure the test suite passes** and the code lints (`npm run lint`).
5. **Update the documentation** if necessary.
6. **Submit a pull request** with a clear description of your changes.

## Development Setup

GreenGlitch is built with:
- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS 4
- **Database/Auth:** Firebase (Firestore & Storage)
- **AI:** Puter AI
- **Maps:** Leaflet & OpenStreetMap

Please follow the installation steps in the [README.md](README.md) to get your local environment set up.

## Style Guidelines

- **TypeScript:** Use strong typing wherever possible.
- **Components:** Keep components small, reusable, and focused.
- **Styling:** Use Tailwind CSS for consistency.
- **Git Commits:** Use descriptive commit messages (e.g., `feat: add community verification`, `fix: sidebar padding on mobile`).

## Questions?

If you have any questions, feel free to open an issue or reach out to the maintainers.

Happy coding! 🚀
